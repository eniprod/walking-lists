# Walking Maps

Calgary riding and poll maps for door-to-door walking sheets.

## Easiest way: use the web page

Open this link in Chrome, Edge, Firefox, or Safari:

https://eniprod.github.io/walking-lists/overlay.html

You do not need to download anything. Ridings should load on their own. You need internet for the street and aerial maps (Esri).

Then skip to **Make a walking map** below.

## Other way: download the files

Use this if you were asked to keep a copy on your computer.

1. On GitHub open **Code → Download ZIP**.
2. Unzip the folder. Keep these three files together and do not rename them:
   - `overlay.html` — the map app
   - `CR_ridings.geojson` — riding boundaries
   - `CR_polls.geojson` — poll boundaries
3. Double-click `overlay.html`, or in your browser use File → Open File… and choose `overlay.html`.
4. You need internet for the street and aerial maps (Esri).
5. If ridings do not appear, click **Link ridings file** and choose `CR_ridings.geojson`, then **Link polls file** and choose `CR_polls.geojson`. The buttons turn green when the files are loaded.

## Make a walking map

1. The first screen shows ridings only.
2. Check a riding or click it on the map. That riding zooms in and its polls appear.
3. Click a poll → **Create walking map**.
4. Choose Streets, Aerial, or Combined.
5. **Save PDF** or **Save PNG**. The file goes to your computer’s Downloads folder.

You can check more than one riding. The map zooms to fit all of them.

## Notes

- Use a current Chrome, Edge, Firefox, or Safari.
- Do not edit the files.

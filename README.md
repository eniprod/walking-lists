# Walking Maps

Calgary riding and poll maps for door-to-door walking sheets.

This folder is all you need:

- `overlay.html` — the map app
- `CR_ridings.geojson` — riding boundaries
- `CR_polls.geojson` — poll boundaries

Keep the three files in the **same folder**. Do not rename them.

## How to use it

1. Download the files (on GitHub: Code → Download ZIP, then unzip).
2. Double-click `overlay.html`, or in your browser use File → Open File… and choose `overlay.html`.
3. You need internet for the street and aerial maps (Esri).
4. If ridings do not appear, click **Link ridings file** and choose `CR_ridings.geojson`, then **Link polls file** and choose `CR_polls.geojson`. The buttons turn green when the files are loaded.

## Make a walking map

1. The first screen shows ridings only.
2. Check a riding or click it on the map. That riding zooms in and its polls appear.
3. Click a poll → **Create walking map**.
4. Choose Streets, Aerial, or Combined.
5. **Save PDF** or **Save PNG**. The file goes to your computer’s Downloads folder.

You can check more than one riding. The map zooms to fit all of them.

## Notes

- Use a current Chrome, Edge, Firefox, or Safari.
- Do not edit the files.
